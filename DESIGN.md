# Pocket Reserve design language (extracted from live CSS, 16 Oct 2026)
Source: https://aapofoundation.github.io/pocket-reserve/ (index.html, landing CSS). Nothing was changed there; assets were not copied (only tokens/patterns re-implemented).

**Mood:** dark night-blue "field" panels with brass/gold trim, warm parchment text, quiet and unhurried. Calm, craft-like, "field guide" feel.

**Palette:** ink #f6efe0, ink-dim #e8dcc4, ghost-ink #f4ead8; gold #d7b56a, gold-hi #f3e2b0, gold-lo #8a6528; brass #c8a86a, brass-mid #8a6528, brass-lo #6b4a0e, brass-ink #2a1d0a; panel #0e141c, panel-deep #0a0f15, panel-lift #121a24; field gradient 180deg #1c2733 → #0e141c 46% → #0a0f15.
**Fonts:** Nunito (variable, body, weights 700-800) and Cormorant Garamond (display: kickers, headings, uppercase with .14em tracking). Fallbacks Palatino/Georgia, system-ui.
**Shape/space:** radius 12px, fluid gutter clamp(16px,4vw,56px), content max ~1100px, tap targets ≥ 44-56px.
**Components:** 
- Panel (`h2-panel`): field gradient, 1px brass border (light top, dark bottom), double inset hairline, tiny gold corner ticks (8px), film-grain overlay at .42, layered drop shadow.
- Primary button: gold gradient #ecd28a→#c9a24f→#b08a38, dark text #1a1208, brass-lo border, inset highlight, 1px press on :active. Ghost button: panel fill, brass-mid border, ghost-ink text.
- Topbar: 44-48px, panel-deep, round brass-ringed mark badge + brand name.
- Kicker: small uppercase Cormorant, gold-hi, letter-spacing .14em. Gold rule: gradient line fading at both ends.
- Stars: gold-gradient 5-point star with brown outline; empty star dark with brass outline (used as progress/rating).
- Motion: subtle, .1-.14s transitions on colour/transform only.
**Copy tone:** short, warm, plain sentences; invitational ("Plant the first seed", "Continue your island"); reassures about saving ("saves in this browser, never sent anywhere"); a quiet footnote line at the end.
**Adaptation here:** chapters→levels, stars→level stars, island→skills map, "Continue" CTA, same save note. Nothing in the originals' art was reused.

## v2: exploration edition (16 Oct 2026)
Presentation follows Pocket Reserve's Civilization-7-style strategy-map look, drawn procedurally on canvas (no external assets): painterly pointy-top hex terrain with soft shading and brush-stroke texture, foam shorelines, brass-trimmed gold UI, leader-portrait NPC cards, fog of war that lifts as regions unlock. Shining Force 2 is used only as the game mechanic: a hero walks the map, enters towns, talks to NPCs, fights gatekeepers (the quizzes), opens chests, and a party HUD shows progress.

**Files:** shared/art.js (terrain, sprites, portraits), shared/world.js (map, hero, dialogue, quests, HUD), shared/engine.js (v1 lessons/quizzes/boss/scoring, now rendering into an overlay), shared/world.css, <app>/world.js (regions, NPCs, names), <app>/content.js (unchanged v1 content).
**Progress:** same localStorage key as v1 (`learning-apps.<app>`); v1 progress loads automatically and the world adds a `w` field (position, chests, caches, taught, simulators).
**Layout:** overworld 36x26 hexes with 8 nodes (7 regions + citadel) joined by a road; each node opens a 15x12-hex town (teacher, guide, Trial Hall + gatekeeper, chest, optional simulator building, south gate).

## v3: AI safety path (16 Oct 2026)
Worlds: `ai-foundations/`, `ai-evals/`, `ai-safety/` (same exploration engine as before; `shared/worldkit.js` builds region/NPC config from compact specs). Home page lists them in order; `portfolio-guide/` is separate.
**Python challenges:** `shared/code.js` + `shared/pyworker.js` run Pyodide 0.26.4 (jsDelivr CDN) in a Web Worker (8 s timeout, worker restarted if code loops). A `t:'code'` question has starter code, visible and hidden tests, progressive hints and a model solution; it is appended as the last question of a level in `<world>/challenges.js`. Offline: the question offers Retry or Skip (counts as unsolved). Solved ids are stored in the existing progress save under `code`.
**Narration:** new worlds use text captions only (`narration/lines2.js`); no audio or video files exist for them.
**Content rules:** cautious wording, contested points marked, no invented citations, toy models and toy numbers only for anything hazardous. Reading list in `ai-safety/content.js` (links checked 16 Oct 2026).

## v4: depth pass (17 Oct 2026)
`shared/extrakit.js` + `<world>/extra.js` add one deeper lesson section and two questions per level, plus six more Python challenges (ev-l4b, ev-l7b, af-l2b, af-l5b, as-l4b, as-l5b). `shared/review.js` adds a spaced-review deck (1/3/7/14/30-day boxes, stored in localStorage `learning-apps.<app>.review`), a 10-question boss round, and (evals and safety worlds) a "Real-model practice" tab of Inspect exercises done outside the game. Pause menu lists both. Content is unreviewed by experts.

## v5: Python Basics world and journey order (17 Oct 2026)
**New world `python-basics/`** (6 regions + citadel, same engine): Valley of Values, Listwood, Loop Heights, Function Forge, Lookup Harbour, Bugfix Highland. `lessons.js` holds the lesson text only (`window.PYB`), so other worlds can show a section; `content.js` holds predict-the-output questions, 4 graded tasks per region (24 total, hidden tests, specific failure messages, worked example, walk-me-through, gated hints, skeleton blanks for early tasks) and the final "Review Council" choices.
**Runnable lesson examples:** `shared/pyplay.js` turns any `.pyx` block into an editable textarea with Run/Reset (free-form code, output or error with line number). It also adds a "Python scratchpad" tab (pause menu, all Python worlds, saved in `learning-apps.scratch`) and the "Python ideas used here" buttons on every code challenge. Buttons open the matching Basics lesson section in a modal (map in `IDEAS`/`FOR` inside pyplay.js).
**Journey:** home page lists Python Basics, AI Foundations, AI Evaluation Skills, AI Safety in that order (Portfolio Guide separate) with per-world progress read from the existing save keys, and a "suggested next" line. Order is a suggestion, not a lock.
**Shared changes:** `code.js` gained `learn`/`walk` support and `CodeQ.run`; `world.js` node layout handles worlds with fewer than 7 regions; menu shows the scratchpad tab.
**Level 1-3 audit:** challenges in the first three regions of the other worlds only use ideas taught in Basics (indexing, slicing, tuples, seeded random, comprehensions with zip/sum/max, sorted with key and lambda, dict get/setdefault, try/except, functions passed as arguments).

## v6: safety depth, agent evals, Expedition, party and capstone (17 Oct 2026)
**Insert kit:** `shared/insertkit.js` inserts levels from `window.NEWLV` (files `lv_*.js`, generated from Python scripts kept outside the repo) into a world in a chosen order and keeps narration, skills and counts in step. Safety uses it via `ai-safety/insert.js`; AI Evals still uses its own `add.js`. `shared/world.js` has a 12-node layout (`BIG12`, 52x34 hexes) for worlds with 11 regions.
**New regions:** Safety gains Flatterers' Court (sycophancy), Watchtower Heights (eval awareness, sandbagging), Mirror Marsh (alignment faking, chain-of-thought faithfulness) and Control Keep (AI control), now 11 regions, each with 4 lesson sections, 5 questions and 2 Python challenges (sy1-2, ea1-2, af1-2, cp1-2). AI Evals gains Agent Proving Grounds (trajectory, outcome and side-effect grading, pass@k vs pass^k, multi-turn) with ag1-4, now 11 regions. Sources named are only papers whose titles were checked on arxiv.org on 17 Oct 2026; early-stage topics carry an "Early-stage field" note.
**Expedition (`shared/expedition.js`, `shared/expcamp.js`, `<world>/exped.js`, `expedition/*.py`):** replaces the "Real-model practice" tab in Evals (5 stages) and Safety (7 stages). Windows-first base camp (PowerShell venv, `doctor.py`, free `mockllm/model` dry run), stages unlock when named regions are cleared, a note (10+ characters) records a stage, +30 XP each, badges Base camp and Expeditioner. Templates were run with `mockllm/model` under inspect-ai 0.3.281. Note: Inspect must be run from the folder holding the task file (absolute task paths failed in testing).
**Party and satchel (`shared/party.js`):** four recurring companions (Pip, Wren, Mara, Vex) join based on progress read from every world's save, appear as a cameo NPC in each town, show in a HUD strip and a Party tab. Solving a Python challenge stores only the definitions (imports, defs, classes, constants) of the learner's own passing code in `learning-apps.satchel`; the Satchel tab lists them.
**Citadel Workshop:** Evals and Safety define `APP.capstone` (`<world>/capstone.js`): a final coding task (`eval_report`, `release_report`) that runs with the satchel functions loaded as a prelude (`prelude` support in `code.js` and `pyworker.js`). Missing pieces are borrowed from the reference and flagged. Opens from Artificer Wren in the Citadel; badge Citadel Artificer.

## v7: Claude Academy pass (17 Oct 2026)
Jensen asked for a comparison with Claude Academy (public pages only) and approved a glossary plus five additions. His rule: keep our own words, rename nothing. The full 20-row language table is kept outside the repo (`/workspace/reviews/claude-academy-language-table.md`).
**"Also called" glossary (`shared/glossary.js`):** one tab in the pause menu of every Python world (Basics, Foundations, Evals, Safety). Our term on the left, the other name on the right, with where it appears; searchable. Covers the 4Ds, context window = working memory, knowledge cutoff, steerability, top-k/top-p, test set = test dataset, trajectory = agent loop output, and both senses of "bias" (a neuron's bias term versus skewed output). A "not covered" group lists MCP, subagents/skills and prompt caching. A "game words" group maps region/Gatekeeper/Trial Hall/Expedition to course section/quiz/exercise/project. Wording is original; the other names were read on public Academy pages on 17 Oct 2026.
**Fluency Fields (Foundations, region 8, `lF`):** inserted last with `InsertKit` (`ai-foundations/insert.js`, content in `lv_fluency.js`, generated outside the repo). Four lesson sections (4Ds mapped onto our skills; four plain facts about how a model works; verify the citation; flattery and pressure), 7 questions with scenarios, and two Python challenges: `fc1` (which citations are unverified) and `fc2` (spot the flatterer). All example citations are invented and say so. Saves are untouched: progress is keyed by level id, so existing clears stay; the all-levels badge now needs 8. Skills map gains "Fluency: working with AI".
**Autocomplete Workshop (`shared/autocomplete.js`, the Fluency Fields simulator):** builds a word-pair chain from editable text, shows the next-word odds, and applies temperature, top-k and top-p in that order (odds sharpened or flattened, then cut to k words, then to the smallest set adding up to p, then renormalised). Seeded random, so "same dials, new luck" is repeatable. Toy: real models use neural networks over word pieces.
**Agent Proving Grounds additions:** two lesson sections (build the loop; read the trace), Python challenges `ag5` call a tool safely (dict of functions, try/except), `ag6` the agent loop with a pretend model and step limit, `ag7` chain, `ag8` route (`ai-evals/lv_loop.js`, appended to `NEWLV.lA`), and the Agent Loop Stepper simulator (`ai-evals/loop.js`). The region now has a simulator, so an old save shows it as one more thing to visit.
**Expedition stage e6 "From a dataset to a scorecard" (AI Evals):** `expedition/scorecard.py`, standard library only (about 100 lines): generate test cases from a template, auto-grade by last number, two fake models with made-up prices, accuracy with Wilson interval, cost per 1,000 correct answers, paired sign test and a plain verdict. Free, offline, Windows-friendly. `shared/expedition.js` gained `play:` stages: a "Run it here" button runs the file in the game's Python box (Pyodide). It sits between stages 3 and 4 and unlocks with the Variance Fens and Tribunal Terraces cleared.
